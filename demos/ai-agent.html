AI Agent — Knowledge Base Q&A

A working portfolio demo: load a knowledge base, connect your own Claude API key, and ask questions — answered strictly from what's loaded, nothing else. It's a small, practical example of the kind of agent an IT team builds so non-technical staff can self-serve answers instead of filing a ticket.

This is the agent's source of truth — the only material it's allowed to answer from. Click "Load Sample KB" to try a bundled example, or upload your own .txt/.pdf. The extracted text is shown below and is fully editable before you ask anything.

This is a bring-your-own-key demo. Your key goes straight from this browser tab to Anthropic's API — it's never sent to or stored on any server we control. It lives in sessionStorage only, so closing this tab clears it automatically.

—

Every question is sent to Claude along with the full knowledge base text as its only allowed source. Ask something the KB covers and it answers from that text; ask something it doesn't cover (try "what's the capital of France?") and it should tell you that instead of guessing — that's what keeps an internal agent from making things up about your systems.

Load a knowledge base and connect your API key, then ask a question.

This demo only loads a knowledge base from a file, on purpose. A browser can't safely talk to a database directly — there's no database driver in JavaScript, and any connection credentials placed in this page would be visible to every visitor's dev tools. A production agent that reads from a real database needs one more hop in between:

🖥️ Browser(this page)
→
🔌 Backend APIholds credentials,
runs a scoped query
→
🗄️ Databaseyour real data

The backend receives the user's question, runs a safe/read-only query against the database, and returns just the relevant text — the browser never sees a connection string or credential. In that setup, the "Upload File" step above would be replaced by a call to that backend API; everything downstream (grounding the system prompt, streaming the answer) works exactly the same way it does here.
