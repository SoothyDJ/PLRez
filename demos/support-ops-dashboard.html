Methodology

This page demonstrates a "Headless BI" concept. Instead of using Tableau/PowerBI, I built a custom frontend to have full control over the UX. The Python backend (shown on right) handles the heavy lifting—cleaning the raw SQL data and calculating rolling averages—before sending lightweight JSON to the browser.
